# memview — open tasks

The index. One line per open task, ordered by id; nothing here is content.
Bodies live in `docs/tasks/<id>.md` — open one before acting on it, the same way
`MEMORY.md` works. A finished task is **deleted** from this file: git is a better
record of what was done than a `[completed]` flag, and a done task that stays
costs every future turn that reads this.
