# #113 — A stale live reading outranks a fresher dashboard one

**Measured live 2026-08-07 19:57Z.** The console showed 5h **13%** / 7d **12%**, age **55 minutes**. The dashboard at the same moment: 5h **22%** / 7d **14%**, taken six minutes earlier, same window instance (resets 22:20Z). The console was nine points low and preferring the worse number.

**The certain half.** `usage::merged` reaches for the dashboard only when the live reading is **absent**:

    let five_hour = live(seen.get(FIVE_HOUR), now_ms)
        .or_else(|| published.as_ref().and_then(|it| it.five_hour.clone()));

Absent is not the same as older. A live figure an hour stale beats a published one six minutes old, and there is no comparison of the two ages anywhere.

**The half still to confirm.** Why the live figure stopped advancing. The candidate is `usage::fresher`: inside one window instance it accepts a candidate only when `candidate.utilization > held.utilization` — **strictly greater** — so a reading that merely *reconfirms* 13% is discarded along with its arrival time. `Seen.at` is then the last *increase*, and `age_ms` is derived from it, so the age line says "time since we last heard" while measuring "time since it last went up". Check against the live stream before acting: `Event::Limit.utilization` is `Option`, and the `rate_limit_event` lines in the transcript carry `status`/`resetsAt`/`rateLimitType` and **no utilisation**, which would be a different cause with the same symptom.

**⚠ Whatever the cause, keep `fresher` doing its job.** It exists because taking the newest arrival made the week's figure flap 81 → 77 → 81 on the console's own beat. The two questions are separate and should be answered separately:
- *which reading is truest?* — the higher utilisation within a window instance, as now;
- *how long ago was this confirmed?* — the most recent arrival, whatever it said.

Conflating them is what lets a current number be reported as an hour old, which is a worse lie than the flapping it replaced: it teaches you to distrust a figure that is fine.
