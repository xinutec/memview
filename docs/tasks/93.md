# #93 — Open a turn on the timeline into what it actually did

The parsing is the built half; the missing half is that none of it is legible. `doing::Row` gives the coarse layer — agent, project, kind, minute, count, verdict, host — and under it sits an effect per command that nothing displays.

A turn should open into its effects, in order, each showing the command that produced it. Files read, files written, what was searched for and with what pattern, what ran, which machine it reached — and the commands that were not understood, shown as not understood rather than omitted. That last part is the difference between a record and a flattering one.

Depends on #92 for the lowering and on #91 for knowing how large the unread tail is.

Worth stating as the test of the whole thing: someone who was not there should be able to open a turn and say what the agent did to the tree, and see for each claim the command it rests on.
