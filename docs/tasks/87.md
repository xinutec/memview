# #87 — The usage figure jumps backwards near a boundary

Reported 2026-08-06. The usage widget sometimes moves up and then back down when it is near the point where it switches between numbers — 92 to 93 and then back to 92.

Worth knowing before touching it: the reading is assembled from the sessions' own streams with the home dashboard behind it for a window nothing has reported yet (crate::usage), so two sources can disagree by a little and the front page polls every five seconds. A figure that goes backwards is the visible half of that.

Whatever the cause, the rule to hold to is that a number which only ever moves one way is worth more than one that is instantaneously right.
