# #120 — A slash command typed in the console stays "waiting to be read" for ever

Typing `/compact` (or any `/command`) from the console leaves the message marked *waiting to be read* permanently, even though the session read it immediately and is acting on it. Seen 2026-08-08 on the `life` session: it was compacting while the console still claimed the message was unread.

## Why

The marker is set and cleared by two different events, and for a slash command the second one never comes.

- `console/src/session.rs` pushes `Event::Accepted{text:"/compact"}` once the bytes reach the pipe. `transcript.ts` `fold()` turns that into an `asked` entry with `queued: true` — the marker.
- The marker is cleared in the `prompt` arm of `fold()`, which promotes the first waiting entry **whose text matches exactly**.
- The CLI expands a slash command locally. What lands in the transcript is not `/compact` but

      <command-name>/compact</command-name>
      <command-message>compact</command-message>
      <command-args>…</command-args>

- `console/src/protocol.rs` `is_plumbing()` drops any message starting with `<command-name>`, so **no `Prompt` event is emitted at all**. Nothing ever matches, and the entry keeps its `queued` flag.

So the marker is telling a lie it has no way to stop telling. Distinct from #111 (which is the marker existing) and #112 (the idle badge).

## Two ways to fix

1. **Reconstruct the echo.** Have `is_plumbing`/`read_recorded` emit `Prompt{ "/<command-name> <command-args>" }` for the `<command-name>` shape instead of dropping it, and keep dropping the rest. This is the honest fix — the message *was* read and the transcript proves it — and it also makes slash commands visible in the transcript at all, which they currently are not.
   ⚠ Check `past.rs::material()` first: it deliberately relies on plumbing being dropped so that `opening` is the first thing a person actually said. Reconstructed commands would make `/compact` the opening line of every resumed session's summary material.
2. **Don't mark it.** In `fold()`, skip `queued` when the accepted text starts with `/`. Cheaper, but it gives up the read receipt for exactly the messages whose effect is hardest to see.

Prefer 1, with the `material()` filter tightened to skip commands.
